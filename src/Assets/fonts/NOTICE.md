# Third-party assets

IBM Plex Sans, Serif and Mono, subset to Latin and the weights the design
system uses (400/500/600/700 sans, 400 serif, 400 mono). SIL Open Font License
1.1 (https://openfontlicense.org), (c) IBM Corp. Vendored as static `.woff2`
files so the panel needs no Google Fonts CDN at runtime — same reasoning as
vendoring Alpine.js in `../js/vendor/`. Update by replacing with a newer
build's matching files.
