# Documenti interni

Materiale di progetto, non destinato all'acquirente. `.gitattributes` lo esclude
dagli archivi generati con `git archive` e `composer archive`, quindi non finisce
nel pacchetto venduto.

| File | Contenuto |
| --- | --- |
| `SPEC.md` | RoleWarden - Specifiche e Roadmap. Fonte di verita' del prodotto: architettura, modello dati, modello dei permessi, design system, matrice funzionalita' per versione. |
| `BRIEF-MVP.md` | Brief di apertura dell'MVP: perimetro, vincoli non negoziabili, ordine di lavoro in sette tappe, definizione di fatto, protocollo con Codex. |

Sono copie esportate dai documenti su Claude. Se una decisione cambia, si aggiorna
prima il documento originale e poi si riesporta qui, altrimenti le due versioni
divergono e non si sa piu' quale valga.
