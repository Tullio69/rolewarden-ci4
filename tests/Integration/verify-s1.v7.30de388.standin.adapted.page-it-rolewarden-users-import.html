Utenti

Importa utenti

Crea molti utenti in una volta da un file CSV. Vedi ogni riga prima che venga creato qualcosa; una riga sbagliata fa rifiutare l'intero file.

Limite
1000 righe (50 con password), 1024 KB
Esempio
Scarica un file di esempio
A

Colonne

01 emailobbligatoria Indirizzo email. Unico tra gli utenti e dentro il file.
02 usernameobbligatoria Da 3 a 30 lettere, cifre o punti. Unico tra gli utenti e dentro il file.
03 rolefacoltativa Slug di un ruolo esistente, come admin. Vuoto dà il ruolo predefinito delle Impostazioni. I ruoli super admin sono rifiutati.
04 passwordfacoltativa Deve rispettare le regole delle password. Vuota: l'utente accede con il recupero della password o riceve una password da un amministratore.
B

File

UTF-8, separato da virgole o punti e virgola, con i nomi delle colonne nella prima riga.
