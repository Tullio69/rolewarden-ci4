Users

Import users

Create many users at once from a CSV file. You see every row before anything is created; one wrong row refuses the whole file.

Limit
1000 rows (50 with a password), 1024 KB
Sample
Download a sample file
A

Columns

01 emailrequired Email address. Unique among users and within the file.
02 usernamerequired 3 to 30 letters, digits or dots. Unique among users and within the file.
03 roleoptional Slug of an existing role, such as admin. Empty gives the default role from Settings. Super admin roles are refused.
04 passwordoptional Must meet the password rules. Empty: the user signs in through password recovery or gets a password from an administrator.
B

File

UTF-8, comma or semicolon separated, with the column names in the first row.
